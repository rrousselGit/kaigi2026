# MCP Example Server

A simple Model Context Protocol (MCP) server written in Dart, offering a `hello_world` tool.

## Features

- Built using `package:dart_mcp` over `stdio` transport.
- Exposes a `hello_world` tool that optionally takes a `name` argument and returns a greeting string.

## Running

To run the MCP server:

```bash
dart run bin/main.dart
```
